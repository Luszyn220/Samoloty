**Link do strony:** https://Luszyn220.github.io/Samoloty/

## Technologie
* HTML5
* CSS3 (Flexbox, Grid)
* JavaScript

## Funkcje
* Pełna responsywność (wersja mobilna z menu)
* Tryb ciemny / jasny
* Miniquiz z wynikiem
* Formularz z walidacją
